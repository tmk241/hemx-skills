# Hemx Skills

Official agent skills for building applications with [Hemx](https://github.com/tmk241/hemx).

These skills provide optional framework guidance for coding agents. The Hemx
README, public APIs, Rustdoc, and tests remain authoritative for supported
behavior.

## Available skill

### `idiomatic-hemx`

Helps agents preserve Hemx's generated-resource and server-owned effect model
when designing, implementing, reviewing, productionizing, or scaling an
application.

Install it from a project root:

```console
npx skills@latest add tmk241/hemx-skills --skill idiomatic-hemx
```

Restart or refresh the agent session after installation so it can discover the
installed `SKILL.md`.
